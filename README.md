# GKS Applicant Assistant - MADE BY YASHIKA



The *GKS Applicant Assistant * is a Python-based NLP-style chatbot designed to help students understand and navigate the *Global Korea Scholarship (GKS-U)* undergraduate application process.




# 🌟 PROJECT OVERVIEW

Applying for GKS can be confusing because applicants often have questions about:

# ✨ FEATURES

- 🇰🇷 *GKS-U Information* — Answers common questions about the undergraduate GKS program.
- 🎓 *Eligibility Guidance* — Provides general guidance about academic and eligibility requirements.
- 📊 *Academic Requirements* — Helps users understand common academic criteria.
- 🎂 *Age Requirements* — Provides general age-related guidance.
- 🛤️ *Application Tracks* — Explains Embassy Track, University Track, and UIC Track.
- 📄 *Document Guidance* — Covers common application documents and certificates.
- 📑 *Transcript Guidance* — Explains questions related to academic transcripts.
- 🖋️ *Apostille & Notarization* — Provides general guidance about document authentication.
- 🌐 *IELTS & TOPIK Guidance* — Answers common language-test questions.
- 📝 *Personal Statement Guidance* — Provides general guidance for preparing a personal statement.
- 📚 *Study Plan Guidance* — Helps users understand what a study plan should contain.
- ✉️ *Recommendation Letter Guidance* — Covers common recommendation-letter questions.
- 🏫 *University & Major Selection* — Provides guidance about choosing universities and majors.
- 🗣️ *Interview Preparation* — Covers common GKS interview topics and mistakes.
- 💰 *Scholarship Benefits* — Explains major scholarship benefits.
- 🇰🇷 *Korean Language Program* — Provides general information about the language-training stage.
- ✈️ *Visa & Arrival Guidance* — Covers general pre-arrival and arrival-related questions.
- 🏠 *Student Life Information* — Provides general information about life in Korea.
- 🔤 *Typo Tolerance* — Attempts to understand questions containing small spelling mistakes.
- 🔄 *Synonym Matching* — Recognizes different words with similar meanings.
- 🧠 *Follow-up Question Context* — Maintains basic context for certain follow-up questions.
- 📈 *Confidence-Based Responses* — Avoids confidently answering when the detected intent is too uncertain.
- 💬 *Interactive Commands* — Supports commands such as help, topics, source, about, and exit.
